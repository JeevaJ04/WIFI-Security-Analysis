# WIFI-Security-Analysis
An advanced AI-powered WiFi Security Analysis and Detection Dashboard built using Python, Flask, HTML, CSS, JavaScript, and Machine Learning.
This project analyzes wireless networks, detects vulnerabilities, identifies rogue access points, performs anomaly detection, and generates professional security reports with interactive charts and dashboards.

🚀 Features
📡 WiFi Network Scanning
Scan nearby WiFi networks
Detect SSID, BSSID, signal strength, channels, and encryption types
Simulated or real-time scanning support
🛡 Security Analysis
Security score calculation
Encryption strength analysis
Vulnerability detection
Open/WEP network identification
🤖 AI-Based Anomaly Detection
Machine Learning powered anomaly detection
Isolation Forest algorithm
Detect suspicious wireless activity
🚨 Rogue Access Point Detection
Evil Twin detection
Rogue AP identification
MAC spoofing detection simulation
📊 Interactive Dashboard
Live statistics
Pie charts
Bar charts
Signal analysis graphs
Encryption distribution charts
📄 Report Generation
PDF report export
CSV export
Security assessment reports
🌐 Modern UI Dashboard
Responsive frontend
Sidebar navigation
Dynamic tables
Interactive charts using Chart.js
